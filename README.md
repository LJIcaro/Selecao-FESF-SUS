# Seleção FESF-SUS

Bem-vindo ao repositório central do meu portfólio para o 14º Processo de Seleção Pública Simplificada da Fundação Estatal Saúde da Família (FESF-SUS).

Este repositório cumpre o requisito básico do edital e atua como um índice centralizado para os desafios técnicos de Formação Complementar desenvolvidos para a vaga de **Desenvolvedor(a) de Sistemas FULL STACK Python React – Pleno**.

## 👨‍💻 Sobre o Perfil Técnico

Como Desenvolvedor Full Stack, foco na criação de sistemas robustos, seguros e escaláveis. Minha atuação técnica é pautada em boas práticas de arquitetura de software e engenharia de banco de dados. Tenho vivência na otimização de performance no PostgreSQL, resolvendo gargalos como o problema N+1, implementando buscas complexas e garantindo a manutenção eficiente de índices. 

Além disso, possuo experiência no desenvolvimento e na escrita de testes unitários para sistemas que lidam com regras de negócio críticas e fluxos de autenticação de usuários, como plataformas de processamento de acordos coletivos, garantindo a integridade e a segurança dos dados.

## 🚀 Desafios Práticos (Formação Complementar)

Abaixo estão os links diretos para os repositórios contendo as soluções para os itens do Barema da seleção. Cada repositório contém seu próprio `README.md` com as instruções exatas de execução e configuração de ambiente.

### 🔗 [Seleção FESF-SUS – 1 F.C](https://github.com/LJIcaro/Selecao-FESF-SUS-1-F.C)
**Objetivo:** Desenvolvimento funcional ponta a ponta (API + Interface).
* **Back-end:** API desenvolvida em Python utilizando o framework **FastAPI** e ORM **SQLAlchemy**.
* **Front-end:** Interface construída com **React/Next.js**, utilizando **Zustand** para a gestão de estado.

### 🔗 [Seleção FESF-SUS – 2 F.C](https://github.com/LJIcaro/Selecao-FESF-SUS-2-F.C)
**Objetivo:** Infraestrutura, Conteinerização e Segurança.
* **Conteinerização:** Aplicação totalmente conteinerizada via **Docker**, contendo os arquivos `Dockerfile` e `docker-compose.yml` funcionais.
* **Segurança:** Implementação de fluxo de autenticação e autorização utilizando **OAuth2**.

### 🔗 [Seleção FESF-SUS – 3 F.C](https://github.com/LJIcaro/Selecao-FESF-SUS-3-F.C)
**Objetivo:** Otimização e Performance.
* **Cache:** Implantação funcional do **Redis** para gerenciamento de cache, visando a alta disponibilidade e a redução da latência nas consultas ao sistema.

### 🔗 [Seleção FESF-SUS – 4 F.C](https://github.com/LJIcaro/Selecao-FESF-SUS-4-F.C)
**Objetivo:** Garantia de Qualidade e Confiabilidade.
* **Testes:** Desenvolvimento funcional de Testes Unitários e de Integração, garantindo a cobertura das regras de negócio utilizando **Pytest** (Back-end) e/ou **Jest** (Front-end).
